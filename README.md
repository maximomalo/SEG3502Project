## Description du projet

Pour ce projet, nous travaillons sur CAR-HMS (Cairn Hiking Management System). C'est un système qui permet au Club de randonnée Cairn de gérer ses randonnées et ses membres.

Les randonneurs peuvent voir les randonnées disponibles, s'inscrire, annuler une inscription et modifier leurs informations. Les organisateurs peuvent créer et annuler des randonnées. Les administrateurs peuvent gérer les randonneurs et générer des rapports.

Le système utilise aussi les informations de la CCN pour les sentiers et un service météo pour les rappels.

## Objectif du livrable 1

L'objectif de ce premier livrable est de faire une première analyse du domaine CAR-HMS et de préparer la structure du projet.

Nous avons identifié les hypothèses, les sous-domaines et les cas d'utilisation. Nous avons aussi créé un diagramme de contexte pour montrer les interactions entre le système et les utilisateurs.

## Contenu du projet

Le livrable comprend :

- Le rapport du livrable 1 avec les hypothèses, le diagramme de contexte et les cas d'utilisation.
- Le modèle du domaine en Kotlin.
- Les interfaces des cas d'utilisation et les DTO.
- Les contrats Cucumber pour décrire les comportements attendus.
